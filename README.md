# Algoritmo de Tensegridad Lógica (ATL)
## Implementación del Criterio Ontológico Mínimo (COM) - Nomofísica

[cite_start]Este repositorio contiene la implementación oficial del **Algoritmo de Tensegridad Lógica (ATL)**, diseñado para garantizar la estabilidad estructural en modelos de lenguaje mediante la tensión dioscúrica[cite: 275, 276].

### Fundamentos
[cite_start]Basado en la **Nomofísica**, el sistema opera bajo el **Criterio Ontológico Mínimo (COM)**, que establece que la resiliencia requiere la interacción entre polos diferenciados: **Cástor** (generación) y **Pólux** (invariancia)[cite: 276, 282, 302].

### Métricas Clave
* [cite_start]**Energía de Tensión ($E_t$):** Divergencia de Kullback-Leibler entre polos[cite: 299].
* **Factor de Tensegridad ($T$):** Relación de tensión/entropía. El sistema es estable si $T > 0$[cite: 300, 302].

### Uso
El código simula la respuesta del sistema ante perturbaciones de tipo OOD (Out-of-Distribution) para validar la resiliencia del Factor T[cite: 277, 312].
